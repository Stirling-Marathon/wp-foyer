# Stirling Changelog

Internal changes for the Stirling Marathon Limited fork of Foyer.

## 1.8.0-stirling.2

- Add read-only Roku REST API endpoints for published Foyer displays and display manifests.
- Resolve display manifests through Foyer's existing active-channel and slide-order logic.
- Return image-background slides for Roku and controlled unsupported records for external webpage slides.

## 1.8.0-stirling.1

- Identify the plugin as Stirling Foyer.
- Add update metadata to prevent WordPress.org from offering the upstream Foyer package over this fork.
